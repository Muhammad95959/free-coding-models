# models.dev catalog enrichment + drift detection vs sources.js

> **Priority**: P2 — kills the manual maintenance burden of `sources.js` (ctx windows, max_tokens, thinking levels drift constantly).
> **Inspiration**: `apmantza/pi-free` — `lib/model-metadata.ts`.
> **Cross-surface**: enrichment runs in shared core; surfaces just read the merged metadata.

---

## 1. Why

`sources.js` is maintained by hand: ~22 providers × N models, each with `[model_id, label, tier, swe_score, ctx]`. The `ctx` (context window) value in particular **drifts constantly** — vendors expand windows (128k → 256k → 1M), and our static copy goes stale within weeks. Same for max output tokens, thinking-level support, and vision capability.

pi-free doesn't hand-maintain this. It fetches the **`models.dev`** catalog (a community-maintained registry of LLM metadata), caches it for 5 minutes with retries + backoff, and overlays it onto provider model lists. We should do the same — but go one better: use it as a **drift detector** that flags when our `sources.js` disagrees with the live catalog.

Two outcomes:
1. **Enrichment**: live `ctx`, `max_tokens`, `supports_reasoning`, `supports_vision`, `thinking_levels` populated automatically.
2. **Drift detection**: a `--check-drift` mode (and a weekly CI job) that diffs `sources.js` against models.dev and reports mismatches — so we update the catalog proactively instead of via user bug reports.

---

## 2. Goals / Non-goals

### Goals
- [ ] Fetch models.dev catalog with retries (3×, 250ms backoff) + 5-min cache.
- [ ] Build a normalized index by `provider/modelId` and by model-name substring.
- [ ] Enrich every model in our merged list with live `ctx`, `max_tokens`, `reasoning`, `vision`, `thinking_levels`.
- [ ] `--check-drift` CLI mode: print a report of mismatches between `sources.js` and models.dev (exit code 1 if any).
- [ ] Weekly CI job that opens a drift issue (or fails the build, Vanessa's call).
- [ ] Offline-safe: if fetch fails, fall back to `sources.js` values silently.

### Non-goals
- Replacing `sources.js` (it's our source of truth for which models to ping; models.dev is metadata overlay).
- Auto-rewriting `sources.js` (we report drift; a human approves the edit).
- Fetching on every TUI render (5-min cache + lazy).

## 3. Technical design

### 3.1 Fetcher: `src/core/models-dev-fetcher.js`

Mirror pi-free's `lib/model-metadata.ts` constants:

```js
const URL_MODELS_DEV = 'https://models.dev/models.json';
const DEFAULT_FETCH_TIMEOUT_MS = 8000;
const MODELS_DEV_CACHE_TTL_MS = 5 * 60 * 1000;  // 5 min
const MODELS_DEV_RETRIES = 3;
const MODELS_DEV_RETRY_DELAY_MS = 250;

let _catalogCache = null; // { expiresAt, promise, allModels, indexes }

export async function fetchModelsDevCatalog({ force = false } = {}) {
  const now = Date.now();
  if (_catalogCache && !force && _catalogCache.expiresAt > now) {
    return _catalogCache.promise;  // share in-flight promise
  }
  const promise = (async () => {
    let lastError;
    for (let attempt = 1; attempt <= MODELS_DEV_RETRIES; attempt++) {
      try {
        const res = await fetch(URL_MODELS_DEV, {
          headers: { 'User-Agent': 'free-coding-models' },
          signal: AbortSignal.timeout(DEFAULT_FETCH_TIMEOUT_MS),
        });
        if (res.ok) return await res.json();
        lastError = new Error(`HTTP ${res.status} ${res.statusText}`.trim());
      } catch (err) { lastError = err; }
      if (attempt < MODELS_DEV_RETRIES) await sleep(MODELS_DEV_RETRY_DELAY_MS);
    }
    console.warn('[models.dev] fetch failed after retries:', lastError.message);
    return null;
  })();
  _catalogCache = { expiresAt: now + MODELS_DEV_CACHE_TTL_MS, promise };
  return promise;
}
```

### 3.3 Enrichment overlay

In `src/core/model-merger.js`:

```js
const meta = await lookupModelDevMeta(model.id, model.label);
model.ctx        = meta?.contextWindow ?? model.ctx;        // live wins, fallback to sources.js
model.maxTokens  = meta?.maxOutputTokens ?? null;
model.reasoning  = meta?.reasoning ?? false;
model.vision     = meta?.vision ?? false;
model.thinkingLevels = meta?.thinkingLevels ?? null;
model.metaSource = meta ? 'models.dev' : 'sources.js';      // provenance for the TUI
```

### 3.5 Offline behaviour

- Fetch failure → enrichment silently skipped, `sources.js` values used, `metaSource = 'sources.js'`.
- TUI shows a small `📡 live` / `📦 cached` chip indicating whether metadata is fresh.
- Never block the TUI on a fetch — fire it in the background, enrich when it lands (re-render).

## 6. Risks & mitigations

| Risk | Mitigation |
|---|---|
| models.dev unavailable / rate-limits us | 3 retries + 5-min cache + silent fallback; never block the UI. |
| models.dev metadata is itself wrong | Provenance chip (`metaSource`) lets the user see the source; `sources.js` is the trusted fallback. |
| Substring match false positives | Prefer exact-id and provider-prefixed matches; substring only as last resort; log mismatches for review. |
| Drift report is noisy | Allow a `--check-drift --threshold N` to only fail if N+ models drift. |
