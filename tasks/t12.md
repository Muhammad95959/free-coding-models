## Summary

Added a new `/models` route to the marketing site (`website/`) that renders the entire free model catalog directly from the project's `sources.js` — the same file the TUI, router-daemon, and OpenCode plugin consume. The page is auto-regenerated on every build, so adding a model to `sources.js` instantly surfaces it on the website with no copy step.

## What ships

### New page — `website/src/routes/models.tsx`
- Compact hero with live counts (222 models · 20 providers · 68 S+ tier · 106 free)
- Sticky filter bar: search, tier chips (multi-select), quota chips (Free / Limited / Metered), provider dropdown, reset
- Sortable table — 8 columns: #, Tier, Model, Provider, SWE%, CTX, Quota, copy-CLI action
- Sticky `<thead>` with the brand lime accent (mirrors the live web dashboard at `web/`)
- Medal-style rank borders (gold / silver / bronze) on the top 3 S+ rows
- Color-coded SWE scores (gold ≥70%, green 50-70%, faint <50%)
- Per-row copy button → clipboard payload: `npx free-coding-models --pick <provider>/<id> --tool opencode`
- Mobile card layout (cards on `< sm`, table on `sm+`)
- Empty state with reset CTA

### Data layer — `website/src/lib/catalog.ts`
- Imports `sources` + `MODELS` from `sources.js` via the `fcm-sources` alias (configured in both `vite.config.ts` and `tsconfig.json`)
- Flattens and enriches every model into a stable `CatalogRow` shape (provider, modelId, tier, swe, ctx, quota)
- Exports sorted `getProviders()`, tier counts, and tier/quota colour palettes
- Type declarations in `website/src/sources.d.ts`

### Provider branding — `website/src/components/ProviderLogo.tsx`
- 20 provider assets copied from `web/assets/providers/` → `website/public/providers/`
- Inline [icon + wordmark] cell, mirrors `web/src/components/atoms/ProviderLogo.jsx`
- Falls back to a colored monogram for legacy providers (OVH, Scaleway) that ship a single full-width wordmark
- CSS `filter: invert(1)` on the mono variants so the wordmarks read as light text on the dark background

### Schema additions — `sources.js`
- Added `quota` (short human-readable string) and `quotaCode` (`free` | `limited` | `metered`) to every provider entry
- Backward-compatible: the CLI, router-daemon, TUI, and OpenCode plugin all ignore unknown fields, no other code touched
- Verified with `node -e "import('./sources.js').then(...)"` — 222 models, 20 providers, all quotas present

### Navigation
- `SiteHeader.tsx` — "Models" added as the first nav item
- `SiteFooter.tsx` — "Models Catalog" added to the Documentation column
- `index.tsx` — new "Browse every model, live" section with a static preview of the top 5 S+ models (lime sticky header + medal borders + colored SWE) and an "Open the catalog →" CTA

### Structured data
- Added `ModelsStructuredData` (ItemList JSON-LD) so search engines get the count + provider attribution
