`free-coding-models` runs on **macOS**, **Linux**, and **Windows**. The recommended install is a one-line npm global install.

## NPM Global Install (recommended)

<Callout type="note" title="Prerequisite">
Requires **Node.js 18.0.0** or higher (`node -v`). That's the only prerequisite — FCM has a single runtime dependency (`chalk`), no native build step, and never needs `sudo`.
</Callout>

```bash
npm install -g free-coding-models
```

Other package managers work too:

```bash
pnpm add -g free-coding-models
yarn global add free-coding-models
bun install -g free-coding-models
```

### Verify

```bash
free-coding-models --version    # prints e.g. 0.5.65
free-coding-models --help       # prints every flag
```

Update later at any time:

```bash
npm install -g free-coding-models@latest
# …or press Shift+U inside the TUI when an update is available
```

<Callout type="tip" title="PATH Troubleshooting">
If `command not found: free-coding-models` occurs after a global install, ensure npm's global bin folder is on your `$PATH`:
```bash
export PATH="$PATH:$(npm config get prefix)/bin"   # in ~/.zshrc or ~/.bashrc
```
</Callout>

## Docker (headless server)

Run the Web Dashboard + Smart Model Router without installing Node.js:

```bash
docker run -p 19280:19280 ghcr.io/vava-nessa/free-coding-models:latest
```

→ Full instructions, env vars, and Docker Compose live on the [Docker Server](/docs/integrations/docker-web) page.

## Desktop System Tray (Tauri)

For desktop users who prefer a native menu-bar icon with background service management, download a bundle from the [GitHub Releases](https://github.com/vava-nessa/free-coding-models/releases) page:

- **macOS** — `.dmg` (Universal, Apple Silicon & Intel)
- **Windows** — `.msi` / `.exe`
- **Linux** — `.AppImage` / `.deb`

---

## Build from Source

For contributing or testing bleeding-edge features:

```bash
git clone https://github.com/vava-nessa/free-coding-models.git
cd free-coding-models
pnpm install
pnpm test      # run the unit-test suite
pnpm start     # launch the local CLI
```

---

## Post-install checklist

```bash
free-coding-models --help        # confirm the CLI is on your PATH
free-coding-models               # launch the TUI, paste a key, pick a model
```
