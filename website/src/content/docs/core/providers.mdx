## Configuring API Keys

### Option 1: Interactive TUI Settings

Press **`P`** in the terminal UI to open the Provider API Key Settings screen. Keys are stored locally in `~/.free-coding-models/config.json`.

### Option 2: Environment Variables

Export keys in your shell (`~/.zshrc` / `~/.bashrc`):

```bash
export GROQ_API_KEY="gsk_..."
export GEMINI_API_KEY="AIzaSy..."
export CEREBRAS_API_KEY="csk-..."
export DASHSCOPE_API_KEY="sk-..."
```

## Filtering Catalog by Origin

Filter models by specific provider origin:

```bash
# Filter models provided by Groq
free-coding-models --origin groq

# Filter models provided by NVIDIA NIM
free-coding-models --origin nvidia

# Filter models provided by Alibaba DashScope (Qwen)
free-coding-models --origin qwen
```

## Unconfigured Models Display

```bash
# Hide models without configured API keys
free-coding-models --hide-unconfigured

# Show all catalog models
free-coding-models --show-unconfigured
```
