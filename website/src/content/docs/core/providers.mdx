# Supported Free AI Providers

`free-coding-models` aggregates endpoints across top free AI model providers:

- **Google AI Studio**: Gemini 2.5 Flash, Gemini 2.5 Pro (Generous free tier RPM).
- **Groq**: Llama 3.3 70B, DeepSeek R1 Distill (Ultra-high speed inference).
- **Cerebras**: Llama 3.3 70B (Fastest token output).
- **HuggingFace Inference API**: Open-source model repository endpoints.
- **Together AI**: Free trial and community tier models.
- **Sambanova Systems**: Llama 3.3 & Qwen 2.5 endpoints.
- **Mistral AI**: Codestral free developer tier.
- **Ollama / Local**: Connect your own local GGUF models running on your machine.

## Managing API Keys

Press `P` in the TUI to open the Settings screen, or update keys directly in `~/.free-coding-models/config.json`.
