# Tier System & Benchmark Scoring

`free-coding-models` categorizes catalog models into standardized performance tiers based on **SWE-bench Verified** scores (self-reported or evaluated via swe-bench.com / swe-rebench.com).

---

## Performance Tiers Scale

The tier scale is defined in `sources.js` as follows:

| Tier | Badge | Score Range | Description | Active Model Examples in `sources.js` |
|---|---|---|---|---|
| **S+ Tier** | <Badge variant="s-plus">S+ TIER</Badge> | **≥ 70.0%** | Frontier coding models | `z-ai/glm-5.2` (82.8%), `minimaxai/minimax-m2.7` (78.0%), `qwen3.6-27b` (77.2%), `openai/gpt-5` (74.9%) |
| **S Tier** | <Badge variant="s">S TIER</Badge> | **60.0% – 69.9%** | High-performance coding models | `openai/gpt-oss-120b` (62.4%), `gemini-2.5-pro` (63.8%), `openai/o3` (69.1%), `gemini-3.1-flash-lite` (62.8%) |
| **A+ Tier** | <Badge variant="a-plus">A+ TIER</Badge> | **50.0% – 59.9%** | Great fast completion models | `openai/gpt-oss-20b` (50.3%), `google/gemma-4-31b-it` (52.0%), `gemini-2.5-flash` (54.0%) |
| **A Tier** | <Badge variant="a">A TIER</Badge> | **40.0% – 49.9%** | Good general utility models | `qwen/qwen2.5-coder-32b-instruct` (47.0%), `deepseek-ai/deepseek-r1` (49.2%), `codestral-2508` (40.0%) |
| **A- Tier** | <Badge variant="b">A- TIER</Badge> | **35.0% – 39.9%** | Decent utility models | `nvidia/nemotron-3-nano-30b-a3b` (38.8%), `stockmark/stockmark-2-100b-instruct` (36.0%) |
| **B+ Tier** | <Badge variant="b">B+ TIER</Badge> | **30.0% – 34.9%** | Average small models | `mistralai/ministral-14b-instruct-2512` (34.0%), `codestral-2501` (34.0%) |
| **B Tier** | <Badge variant="b">B TIER</Badge> | **20.0% – 29.9%** | Below average / lightweight | `llama-3.3-70b-versatile` (22.0%), `meta/llama-3.2-11b-vision-instruct` (28.0%) |
| **C Tier** | <Badge variant="c">C TIER</Badge> | **< 20.0%** | Edge / lightweight models | `microsoft/phi-4-mini-instruct` (14.0%), `llama-3.1-8b-instant` (18.0%) |

## Filtering and Sorting via CLI

Filter models by tier directly:

```bash
# Filter S+ Tier models
free-coding-models --tier S+

# Filter S Tier models
free-coding-models --tier S

# Filter A+ Tier models
free-coding-models --tier A+
```

Sort by benchmark score:

```bash
free-coding-models --sort swe --desc
```

---

## Drift Detection (`--check-drift`)

To compare local `sources.js` definitions against upstream `models.dev` data:

```bash
free-coding-models --check-drift
```
