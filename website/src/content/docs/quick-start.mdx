# Quick Start Guide

Start querying free models in seconds from your command line.

## 1. Launch the interactive TUI

Run the binary without parameters to enter the interactive terminal UI:

```bash
free-coding-models
```

Navigate with Arrow Keys `↑`/`↓`, sort by SWE score with `S`, filter by tier with `T`, and select a model with `Enter`.

## 2. Pick the Best Model directly

To output the current top-rated model for immediate use:

```bash
free-coding-models --best
```

## 3. Filter by Tier

Filter models in Tier S+ or S:

```bash
free-coding-models --tier S+
```

## 4. OpenCode CLI Integration

Launch directly with OpenCode CLI integration:

```bash
free-coding-models --opencode
```
