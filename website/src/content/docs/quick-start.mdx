# Quick Start Guide

---

## 1. Create Free Provider Accounts & Get API Keys

Before querying cloud endpoints, obtain free API keys from developer portals:

| Provider | Portal Account Creation Link | Key Environment Variable |
|---|---|---|
| **Google AI Studio** | [aistudio.google.com](https://aistudio.google.com/) | `GEMINI_API_KEY` |
| **Groq Console** | [console.groq.com/keys](https://console.groq.com/keys) | `GROQ_API_KEY` |
| **Cerebras Cloud** | [cloud.cerebras.ai](https://cloud.cerebras.ai) | `CEREBRAS_API_KEY` |
| **NVIDIA NIM** | [build.nvidia.com](https://build.nvidia.com) | `NVIDIA_API_KEY` |
| **Alibaba DashScope** | [modelstudio.console.alibabacloud.com](https://modelstudio.console.alibabacloud.com) | `DASHSCOPE_API_KEY` |
| **GitHub Models** | [models.github.ai](https://models.github.ai) | `GITHUB_TOKEN` |
| **Mistral AI** | [console.mistral.ai](https://console.mistral.ai) | `MISTRAL_API_KEY` |
| **Cloudflare AI** | [dash.cloudflare.com](https://dash.cloudflare.com) | `CLOUDFLARE_API_KEY` |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | `OPENROUTER_API_KEY` |
| **SambaNova Cloud** | [cloud.sambanova.ai](https://cloud.sambanova.ai) | `SAMBANOVA_API_KEY` |
| **Scaleway** | [console.scaleway.com/iam/api-keys](https://console.scaleway.com/iam/api-keys) | `SCALEWAY_API_KEY` |

Export keys in your shell (`~/.zshrc` or `~/.bashrc`):

```bash
export GROQ_API_KEY="gsk_..."
export GEMINI_API_KEY="AIzaSy..."
export CEREBRAS_API_KEY="csk-..."
```

## 2. Interactive Terminal UI

Run `free-coding-models` without arguments to launch the ANSI terminal UI:

```bash
free-coding-models
```

- **`↑` / `↓`**: Navigate catalog rows.
- **`S`**: Sort models by SWE-bench score.
- **`T`**: Cycle tier filter (`All` → `S+` → `S` → `A+` → `A` → `A-` → `B+` → `B` → `C`).
- **`P`**: Open Provider API Key Settings overlay.
- **`Enter`**: Select active model.

---

## 3. One-Liner CLI Queries

```bash
# Print top-performing model string
free-coding-models --best

# Filter S+ Tier models
free-coding-models --tier S+

# Filter high reliability models (>98% uptime)
free-coding-models --fiable

# Output catalog as JSON
free-coding-models --json | jq '.[0]'
```

## 4. Background Proxy Daemon & Web Server

Start the local proxy daemon at `http://localhost:19280/v1`:

```bash
free-coding-models --daemon-bg
```

Check status:

```bash
free-coding-models --daemon-status
```

Test cURL query:

```bash
curl http://localhost:19280/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fcm",
    "messages": [
      {"role": "user", "content": "Write a Python string reverse function."}
    ]
  }'
```
