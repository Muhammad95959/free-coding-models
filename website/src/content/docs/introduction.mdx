# Introduction & Architecture

`free-coding-models` is an open-source local gateway, health monitoring engine, and model router for free AI coding model endpoints.

It aggregates models from providers including Google AI, Groq, Cerebras, NVIDIA NIM, GitHub Models, Mistral AI, Scaleway, Alibaba DashScope, Cloudflare AI, OVHcloud, OpenRouter, SambaNova, OpenCode Zen, Kilo, LLM7, Routeway, Novita, and Ollama Cloud.

---

## Core Capabilities

1. **Local OpenAI-Compatible Proxy**: Exposes `http://localhost:19280/v1` with model `"fcm"`.
2. **Transparent Auto-Failover**: Automatically shifts requests to an alternative model in the active set when HTTP 429 (rate limit) or 5xx errors occur.
3. **SWE-Bench Tiering**: Categorizes catalog entries into performance tiers (`S+`, `S`, `A+`, `A`, `A-`, `B+`, `B`, `C`) based on SWE-bench Verified scores.
4. **Passive Quota Header Parsing**: Inspects `x-ratelimit-remaining` and reset headers on live responses to detect rate limits before requests fail.
5. **Multi-Surface Interfaces**: Includes interactive terminal UI (ANSI), Tauri desktop tray utility, Web Dashboard, Docker image, and OpenCode/OpenClaw configuration tools.
