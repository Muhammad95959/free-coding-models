`free-coding-models` (FCM) pings every model in parallel, shows live latency, and computes a **live Stability Score (0–100)** so you know which free coding model is fastest *right now* — and which is actually reliable. Once you've picked a model, FCM writes it straight into your coding tool's config and launches it.

There are **~222 cataloged free or free-limited coding models** across 20 vetted providers (NVIDIA NIM, Groq, Cerebras, Google AI Studio, GitHub Models, Mistral, Cloudflare Workers AI, OpenRouter, SambaNova, OVHcloud, Scaleway, Alibaba DashScope, OpenCode Zen, Kilo, LLM7, Routeway, Novita, Ollama Cloud, and more).

## Four surfaces, one engine

FCM ships as **four surfaces**, all powered by the same engine:

| Surface | What it is | When to use it |
|---|---|---|
| 🎛️ **TUI** | The interactive terminal dashboard | The default. Live ranking, pick + launch a model. |
| 🌐 **Web Dashboard** | A browser control center | Browse from your browser, share filtered views, run headless in Docker. |
| 🔌 **Extensions** | OpenCode & Pi agent plugins | Hot-swap models mid-session without leaving your agent. |
| 🔀 **Router** | A local OpenAI-compatible daemon | One localhost endpoint that auto-fails-over between free models. |

> The **TUI and Web Dashboard are the core** of the product — that's where most users live. Extensions and the Router build on top of the same engine and are covered later.

## Core capabilities

1. **Live ranking** — all models pinged in parallel via native `fetch`; real round-trip latency, not guesswork.
2. **Stability Score** — a composite 0–100 score (p95 latency 30%, jitter 30%, spike rate 20%, uptime 20%) that reveals which models are *consistently* fast, not just lucky.
3. **SWE-bench Tiering** — every model is tiered by its SWE-bench Verified score (`S+`, `S`, `A+`, `A`, `A-`, `B+`, `B`, `C`).
4. **One-key launch** — `Enter` writes the model into your tool's config and launches it; pre-target a tool from the CLI or cycle it live with `Z`.
5. **Smart Model Router** — an optional local OpenAI-compatible daemon (`http://localhost:19280/v1`) with automatic failover between free models when one 429s or 5xxs.
