# Introduction to free-coding-models

**free-coding-models** is a zero-cost, open-source model gateway and model management ecosystem. It provides continuous real-time latency pinging, condition tracking, SWE bench ranking, and auto-failover across 100+ free AI coding models from Google Gemini, DeepSeek, Groq, Cerebras, HuggingFace, Together, Sambanova, and local Ollama instances.

## Why free-coding-models?

- **100% Free Coding Tier**: Access state-of-the-art coding LLMs without paying monthly subscriptions.
- **Auto-Failover & High Availability**: Automatically switch providers when rate limits or quotas are reached.
- **SWE Score Ranking**: Filter models by benchmark quality (`--best`, `--fiable`, `--tier S+`).
- **Multi-Surface Compatibility**: Seamlessly use the CLI/TUI, Desktop System Tray app, OpenCode CLI plugin, OpenClaw integration, or Docker API.

## Core Features

- Real-time latency & health checks (`getUptime`, `getAvg`, `getVerdict`).
- Standardized Tier System (`S+`, `S`, `A+`, `A`, `B+`, `B`, `C`).
- Key management for all major free AI API providers.
- Custom local model source support (`Ollama`, `LM Studio`, custom endpoints).
