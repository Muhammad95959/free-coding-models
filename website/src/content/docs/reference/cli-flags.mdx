# CLI Flags & Commands

| Flag | Short | Description |
|---|---|---|
| `--best` | `-b` | Select and print the top-performing model instantly |
| `--fiable` | `-f` | Filter models with high uptime reliability (>98%) |
| `--tier [T]` | `-t` | Filter catalog by tier (`S+`, `S`, `A+`, `A`, `B+`, `C`) |
| `--opencode` | | Export configuration to OpenCode CLI |
| `--openclaw` | | Patch models into OpenClaw configuration |
| `--help` | `-h` | Print help manual |
| `--version` | `-v` | Output installed package version |
