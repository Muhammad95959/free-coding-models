## Tool launchers

Start the TUI pre-configured for a tool, then `Enter` writes the model into that tool's config **and launches it**. The default (no tool flag) is **OpenCode CLI**. Press `Z` in the TUI to cycle tools without restarting.

## Filtering & display

| Flag | Description |
|------|-------------|
| `--best` | Show only top tiers (A+, S, S+) |
| `--premium` | Start with an S-tier filter + verdict sort (resettable in-app) |
| `--tier <S\|A\|B\|C>` | Filter by tier family — `S` = S+/S, `A` = A+/A/A-, `B` = B+/B, `C` = C only |
| `--origin <provider>` | Filter by provider (e.g. `nvidia`, `groq`, `cerebras`) |
| `--hide-unconfigured` | Hide models whose provider has no API key |
| `--show-unconfigured` | Show all models regardless of key configuration |

## Sorting

| Flag | Description |
|------|-------------|
| `--sort <column>` | Start sorted by a specific column |
| `--asc` | Sort ascending |
| `--desc` | Sort descending |

Valid `--sort` columns: `rank`, `tier`, `origin`, `model`, `ping`, `avg`, `swe`, `ctx`, `condition`, `verdict`, `uptime`, `stability`, `aiLatency`, `tps`.

## Output modes

| Flag | Description |
|------|-------------|
| `--json` | Skip the TUI — print all results as JSON and exit (great for `jq`) |
| `--fiable` | Wait 10s, pick the most reliable model, print `provider/model_id` and exit |
| `--recommend` | Open Smart Recommend immediately on startup |

## Runtime options

| Flag | Description |
|------|-------------|
| `--ping-interval <ms>` | Override the ping interval in milliseconds |
| `--reprobe` / `--no-cache` | Rebuild the persistent probe-cache this run |
| `--probe-ttl <ms>` | Override the probe-cache TTL (default 24h) |
| `--show-broken` | Don't auto-hide broken models this run |
| `--check-drift` | Diff `sources.js` against `models.dev`; exit 1 on mismatch |
| `--drift-threshold <N>` | Only fail `--check-drift` when N+ mismatches are found |
| `--no-telemetry` | Disable anonymous telemetry for this run |

## Server & maintenance commands

| Command / Flag | Description |
|----------------|-------------|
| `web` / `--web` / `--gui` | Start the catalog-only Web Dashboard on `http://localhost:3333` (`FCM_WEB_PORT`) |
| `playground` / `--playground` | Open the in-TUI Playground chat overlay (auto-starts the router if needed) |
| `--daemon` | Start the Smart Router daemon + Web Dashboard (foreground, port `19280`) |
| `--daemon-bg` | Start the daemon detached in the background |
| `--daemon-status` | Print router daemon status JSON |
| `--daemon-stop` | Gracefully stop the router daemon |
| `--sync-set [name]` | Auto-discover and live-probe models into a router set |
| `--help` / `-h` | Print this help text and exit |
| `--version` / `-v` | Print the package version |

> The catalog `web` dashboard runs on **port 3333**; the `--daemon` mode runs the full dashboard **+ router** on **port 19280**.

## Examples

```bash
# Crush, pre-filtered to S-tier only
free-coding-models --crush --tier S

# Get the fastest S-tier model ID (headless, for scripts)
free-coding-models --tier S --json | jq -r '.[0].modelId'

# Most reliable model right now
free-coding-models --fiable

# Start the local Smart Model Router endpoint
free-coding-models --daemon-bg

# Elite-focused preset (resettable in-app)
free-coding-models --premium

# Sort by SWE score descending
free-coding-models --sort swe --desc

# Groq models only
free-coding-models --origin groq
```
