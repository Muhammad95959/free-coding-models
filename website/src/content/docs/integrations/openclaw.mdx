# OpenClaw Integration

Inject free model provider configurations into **OpenClaw** agents.

---

## 1. Automatic Patching

Patch OpenClaw model configuration (`~/.openclaw/config.json`):

```bash
free-coding-models --openclaw
```

---

## 2. Combined Filtering Flags

Inject specific tiers or high-uptime models into OpenClaw:

```bash
# Inject S-tier models only
free-coding-models --openclaw --tier S

# Inject models with >98% uptime
free-coding-models --openclaw --fiable
```
