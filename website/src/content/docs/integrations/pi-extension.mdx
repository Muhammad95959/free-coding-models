# Pi Agent Extension (`packages/fcm-pi`)

`free-coding-models` provides a native extension for the **[Pi coding agent](https://pi.dev)** located at [`packages/fcm-pi`](file:///Users/vava/Documents/GitHub/free-coding-models/packages/fcm-pi).

## Key Features

- **Silent on Boot**: No automatic scans, footers, or forced model switches on Pi agent startup or `/resume`.
- **Parallel Probing (`/fcm`)**: Scans candidate models in parallel only when requested, scoring them by SWE-bench (60%), latency (20%), TPS (10%), and stability (10%).
- **Branded Progress Footer**: Live scan progress displays `> free-coding-models` badge with percentage counter in the terminal.
- **Error-Triggered Picker**: If an active model returns 4xx/5xx errors, Pi re-opens the selection menu and marks the failing model `🔴 BUGGED`.
- **Context Window Safety Filter**: Hides models with context windows too small for agent reasoning (e.g. 8k models).

---

## Installation in Pi Agent

Add the package path to your `~/.pi/agent/settings.json`:

```json
{
  "packages": [
    "/Users/<your-username>/Documents/GitHub/free-coding-models/packages/fcm-pi"
  ]
}
```

Or point to `pi-extension/` for legacy compatibility wrapper paths.

## Pi Slash Commands

| Command | Action | Description |
|---|---|---|
| `/fcm` | Scan & Select | Runs parallel model scan and opens interactive model picker |
| `/fcm-list` | Ranked Table | Displays top 20 models ranked by composite score |
| `/fcm-router` | Connect Router | Connects Pi session directly to local FCM Smart Router daemon |
| `/fcm-status` | Diagnostics | Displays current active model, cache state, and daemon health |
