# Desktop System Tray App

The Desktop application runs as a lightweight menu bar / system tray utility.

## Features

- **Live System Tray Status**: Visual indicator of catalog health and current active model.
- **One-click Model Switcher**: Quickly switch models from your desktop menu bar.
- **Local API Proxy**: Background server running on `http://127.0.0.1:19280`.
