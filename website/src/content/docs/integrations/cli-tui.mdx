# CLI & Terminal UI Guide

The interactive terminal interface is engineered with raw ANSI escape codes for instant performance and zero-lag rendering.

## Keybindings Reference

| Key | Action |
|---|---|
| `↑` / `↓` | Navigate catalog rows |
| `Enter` | Select active model |
| `T` | Cycle tier filter (`All` → `S+` → `S` → `A+` → `A` → `B+` → `C`) |
| `P` | Open Provider Settings modal |
| `S` | Sort by SWE Bench score |
| `Y` | Sort by Tier |
| `A` | Sort by Average Ping |
| `R` | Sort by Rank |
| `Ctrl+P` | Open Command Palette |
| `Esc` | Close modal / palette |
| `Ctrl+C` | Quit TUI |
